{{< hint type=important >}}
O Assistente de IA é um recurso em preview e pode ser alterado antes do lançamento final. Você precisa de uma chave de API OpenAI válida para usá-lo.
{{< /hint >}}

![AI Assistant](https://blog.lpains.net/images/posts/sharp-cooking-ai-preview-2.jpeg)

O Assistente de IA permite que você tenha uma conversa com uma IA que conhece seu livro de receitas. Você pode fazer perguntas como "O que posso fazer com frango e limão?" ou "Me dê os passos da minha receita de macarrão de forma mais simples."

## Habilitando o Assistente de IA

Antes de usar o Assistente de IA, você deve habilitá-lo na página de **Recursos em Preview**:

1. Abra a página de **Opções**.
2. Toque em **Recursos em Preview**.
3. Habilite o **Chat de IA**.
4. Insira sua **Chave de API OpenAI** e escolha um **Nome do Modelo OpenAI** (por exemplo, `gpt-4o`).

{{< hint type=tip >}}
Você pode obter uma chave de API OpenAI em [platform.openai.com](https://platform.openai.com). As tarifas padrão de uso da OpenAI se aplicam.
{{< /hint >}}

## Iniciando um chat

Quando habilitado, um ícone de chat aparece na página de lista de receitas. Toque nele para abrir a interface de chat e começar a fazer perguntas sobre suas receitas.

O assistente pode referenciar várias receitas do seu livro para fornecer respostas contextuais.

## Nota de privacidade

Suas receitas são enviadas para a OpenAI para gerar respostas. Revise a [Política de Privacidade](/web/privacy-policy) e a política de privacidade da OpenAI antes de habilitar este recurso.
